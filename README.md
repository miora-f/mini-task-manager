### Mini Task Manager

A simple and user-friendly task manager built with HTML, CSS, and JavaScript.

### About the Project

Mini Task Manager is a small web application that helps users organize their daily tasks. It was created as a personal project to practice front-end web development and improve my programming skills.

### Features

Add new tasks

Mark tasks as completed

Delete tasks

Simple and user-friendly interface

Responsive layout

### Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and layout

JavaScript – Interactive functionality
